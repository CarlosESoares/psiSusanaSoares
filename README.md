# Site da Psicóloga Susana Soares

![Status](https://img.shields.io/badge/status-em%20desenvolvimento-yellow)
![License](https://img.shields.io/badge/license-MIT-blue)

Website profissional desenvolvido para a **Psicóloga Susana Soares**, com o objetivo de apresentar sua atuação profissional, abordagens terapêuticas, áreas de atendimento e formas de contato.

O projeto busca criar uma experiência digital **acolhedora, profissional e acessível**, permitindo que novos pacientes conheçam o trabalho da psicóloga e encontrem informações importantes antes de iniciar o acompanhamento.

## Sobre a profissional

**Susana Soares** é psicóloga, registrada no **CRP 06/128165**, com atuação especializada em **Terapias Comportamentais**.

Sua atuação inclui diferentes abordagens e áreas relacionadas à saúde mental e ao desenvolvimento pessoal, entre elas:

* Terapia Cognitivo-Comportamental;
* Terapia de Aceitação e Compromisso (ACT);
* Terapia do Esquema;
* Análise do Comportamento / Behaviorismo;
* Mindfulness;
* Coaching de Carreira;
* Coaching Executivo.

Entre os temas trabalhados estão:

* Ansiedade;
* Depressão;
* Estresse;
* Burnout;
* Autoestima;
* Autoconhecimento;
* TDA/TDAH;
* Morte e luto;
* Desenvolvimento profissional;
* Coaching executivo.

A profissional também realiza **atendimento em inglês** e atende **adultos e idosos**.

## Objetivo do projeto

O site tem como principais objetivos:

* Apresentar a psicóloga e sua trajetória profissional;
* Explicar de forma clara suas abordagens terapêuticas;
* Apresentar as principais áreas de atuação;
* Facilitar o primeiro contato com a profissional;
* Direcionar visitantes para os canais de atendimento e agendamento;
* Criar uma presença digital profissional;
* Oferecer uma experiência agradável tanto em computadores quanto em dispositivos móveis.

## Executando o projeto

### Pré-requisitos

Para executar o projeto localmente, é necessário possuir:

* Git;
* Visual Studio Code ou outro editor de código;
* Navegador web.

### Clonando o repositório

```bash
git clone https://github.com/SEU-USUARIO/site-psicologa-susana-soares.git
```

Entre na pasta:

```bash
cd site-psicologa-susana-soares
```

### Executando

Caso esteja utilizando o **Visual Studio Code**, recomenda-se utilizar a extensão **Live Server**.

Abra o arquivo:

```text
index.html
```

e execute através do Live Server.

## 🔐 Privacidade e segurança

Por se tratar de um site relacionado à psicologia, o projeto deve ter atenção especial à **privacidade dos visitantes e à proteção de dados pessoais**.

Caso sejam implementados formulários ou outros mecanismos de coleta de informações, eles deverão seguir boas práticas de segurança e os princípios estabelecidos pela **Lei Geral de Proteção de Dados (LGPD)**.

O site também deve evitar a exposição desnecessária de informações sensíveis relacionadas aos pacientes.
